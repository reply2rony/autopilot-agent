# Facebook Viral Strategy (in the autopilot agent)

Source of truth: ~/workspace/social-growth/GROWTH-SYSTEM.md R1-R13.

## What the algorithm rewards (extracted)
- Early engagement velocity: comments in the first hour matter most. Reply to every comment within the first hour where possible.
- Native video over links: NO direct links in any Facebook post text (kills reach, R4). Cross-promotion on FB = naming the platform + what is there, never a URL. Links go in comments/blogs/pins, not post text.
- Hook first: hook line -> value line -> CTA. Barta: hook title first, then short description, then hashtags, censor words broken with / (R7), allegations as অভিযোগ, no external links.
- One idea per post, series formats so followers expect the next one.
- Profile rules (Rony Cn): max 2 posts/day (1 video ~20:00 + 1 daytime image post, R1), every post carries a colorful thumbnail-style image (R2), NO hashtags in profile captions (R3), NOTHING auto-posts to the profile without Rony's approval (R5).
- Page rules (Barta Prime): 5 photo posts/day, 12:00-20:00 window, every FB post mirrored to IG @bartaprime, hashtags allowed on the Page (not the profile).
- Engagement tactics that stay: 5 meaningful niche comments/day (not 20), weekly liker-invite batch, question-led first lines on hot topics.
- Rejected, permanently: paid boosts, giveaways, FB groups for link sharing, cross-post-everything, bought followers / engagement pods.

## Content mix (Rony Cn, 14 posts/week)
~7 videos (reach) / ~4 value image posts (saves/shares) / ~2 engagement polls or questions (comments) / ~1 personal/behind-the-scenes (trust). The old 10% "blog links" slice is deleted (R4).
