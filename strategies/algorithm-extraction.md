# Algorithm Extraction (how the agent reads the algorithm, weekly)

The agent does NOT guess the algorithm. It extracts it from the venture's own data, every Sunday 21:00 +06 review:

1. Pull the week's real numbers (never invent): YouTube Studio (CTR, retention, viewed-vs-swiped), Facebook Professional Dashboard / Page Insights (reach, follows, comments, shares, saves), Pinterest Analytics (impressions, outbound CTR, saves), Blogspot stats, Search Console (impressions, avg position, clicks).
2. Rank the week's top 3 and bottom 3 pieces. For each, record: hook, topic, format, design, posting time, first-hour comments.
3. Extract the pattern: which hook style won, which topic cluster won, which thumbnail/headline formula won, what time won. One variable at a time — never change hook + time + format together, or the lesson is lost.
4. Apply next week: winners get sequels/variants ("Part 2" is the cheapest viral bet), losers get stopped or reworked once (48h rule on YouTube long-form), then stopped if they fail again.
5. Competitor extraction (niche scan): top accounts in the niche, their best posts ranked by multiple-over-median, hook patterns and formats noted — then rebuilt as 100% original content, never clipped or copied. Originality check in the QC gate rejects anything too close to a competitor post.
6. Guard: after every extraction, answer the house questions — did anything bend a locked rule? What is sitting in Rony's approval queue? Which venture got the least attention, and is that deliberate?
